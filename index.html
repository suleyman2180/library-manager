Gemini API (Ücretsiz Kitap Sorgulama)

%100 Ücretsiz

ISBN veya Kitap Adı ile arama yapıldığında Kitap Adı, Yazar, Yayınevi, Sayfa Sayısı, Basım Yılı ve Kategori bilgilerinin %100 eksiksiz ve hızlı bulunması için ücretsiz Gemini API anahtarınızı tanımlayabilirsiniz.
Google AI Studio'dan (aistudio.google.com) ücretsiz API Key alabilirsiniz.

ISBNdb API

ISBN sorgusu ve yayınevinden toplu ekleme için isbndb.com REST anahtarı (İsteğe bağlı). Anahtar yalnızca sunucuda saklanır, tarayıcıya geri gönderilmez.
